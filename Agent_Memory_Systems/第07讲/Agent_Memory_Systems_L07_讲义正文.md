## 本讲导读：从“找得到文字”走向“找得到意思”

第06讲讲过：当若干段文本已经进入大模型当前上下文后，模型内部会通过向量表示、注意力和多层网络加工它们。本讲研究另一个位置上的技术：**大量历史记忆没有全部进入上下文时，智能体如何先找到“意思相关”的那几条？**

想象一个持续一个月的科研助手。第4天，研究者说：“现在的评估器把工具超时也算成了智能体的错误，需要单独处理。”第28天，研究者询问：“上次为什么要修改失败归因规则？”两段话几乎没有重复的关键词；但熟悉上下文的人知道，后者在寻找前者。只依靠字符串完全一致的搜索可能漏掉它，而一个训练得当的语义表示模型可能把它们映射到相近的位置。

这就是**文本嵌入（Text Embedding）**最直观的价值：用一组有序的数字表示文本，为机器提供可计算的相似性线索。它不是把句子变成“有灵魂的坐标”，也不是证明一段内容为真；它只是为特定训练目标学到的一种**近似语义表示**。

**学完本讲，你应能独立解释并推导：**① 什么是向量、维度、长度和方向；② 两条记忆的相似度如何计算；③ 为什么点积、欧氏距离和余弦相似度可能给出不同排序；④ Embedding模型通过什么样的训练学会“相近”；⑤ 从记忆写入到检索再到行动的完整链路；⑥ 如何识别否定、时间、版本、实体编号等引起的记忆检索错误。

## 1. 为什么关键词匹配还不够？从一个真实问题类型出发

先看三条**虚构的科研记忆**，其中括号里的日期只是教学案例，不表示任何真实科研项目：

- **记忆 A（第4天）**：“工具响应超时属于运行基础设施异常；不能直接记为模型业务失败。”
- **记忆 B（第12天）**：“需要更新实验报告模板，为不同失败类型增加独立统计字段。”
- **记忆 C（第20天）**：“实验方案仍在审核，尚未授权新增付费调用。”

第30天问：“我们以前为什么强调要把网络故障与智能体决策错误分开？”你大概会选择A，有时也可能补充B。为什么？因为“工具超时”和“网络故障”在这个问题里属于相关的故障类型；“模型业务失败”和“智能体决策错误”也讨论相近的归因边界。

传统的关键词检索（Lexical Retrieval）主要依据词项是否重合、词频和统计信息等寻找材料。如果提问和记忆措辞差异很大，就可能漏掉有用材料。**语义检索（Semantic Retrieval）**把问题和候选记忆都转成可比较的向量，尝试使用数值空间中的相似关系弥补词面差异。

但不能因此认为语义检索无条件优于关键词检索。恰好相反，“课题编号2026-KF-021”“某个文件的SHA256”“否定词‘尚未’”等精确细节，往往需要原文、精确过滤和词项匹配参与。下一讲会系统介绍检索方法，本讲先弄懂其核心数学基础。

### 1.1 记忆检索是先找候选，不是直接产生可靠答案

一条记忆被找回来，并不意味着它一定是准确的、最新的或具有执行权限。假设检索结果中有“第4天提出的方案”和“第20天否决的方案”，如果只凭语义相似分数决定下一步，就可能把一个已经废弃的意见当成当前决定。

所以本讲有一条贯穿原则：**向量用于发现候选关系；时间、来源、权限和证据用于判断候选内容是否可以被使用。**

## 2. 什么是向量？先把抽象数字变成空间里的箭头

### 2.1 一个数、两个数、三个数

数学上，一个数字如“7”叫标量（Scalar）。把若干数字按顺序排成一组，例如 **(3, 4)**，就得到一个二维向量（Vector）。你可以把它看成从坐标原点出发、指向横坐标3、纵坐标4的箭头。**(3, 4, 2)** 是三维向量，需要三个坐标轴；一般的 d 维向量写作 **x = (x₁, x₂, …, x_d)**。

有两件事一定要理解。第一，**维度**是坐标的数量，不是段落有多少个词。第二，向量的每一维不必对应一个人类能单独命名的含义；在训练出的高维语义向量里，语义通常是多维分布式编码的。

假设我们给文本做一个二维的**教学示意**：x轴暂时理解为“涉及运行系统的程度”，y轴理解为“涉及科研决策的程度”。“工具调用失败”和“模型参数非法”可能靠得较近，“周末买菜”可能离得较远。这个示意有助于理解“空间相近”，**但真实模型中的第1维、第2维并不一定有这种稳定、可解释的名字**。

**图2｜二维向量、坐标与长度示意。**（PDF中有对应的彩色示意图。）

### 2.2 向量的长度怎么算？

把箭头的起点放在原点，(3,4)的长度可以通过初中几何中的勾股定理计算：横着走3格，竖着走4格，斜边长5。写成公式就是：

**||x|| = √(x₁² + x₂² + … + x_d²)**。

例如 x=(3,4)，则 ||x||=√(3²+4²)=√25=**5**。你现在不用记住希腊字母或函数库调用；只要明白“多个维度共同构成一个整体长度”。

### 2.3 方向为什么也重要？

向量 (3,4) 和 (6,8) 的方向完全相同，但第二条箭头是第一条的两倍长。它们如果表示两条文本，是否应该视为“同样语义方向”？这取决于我们采用的比较规则：有些指标更关注方向，有些同时受长度影响。

## 3. 三种比较方法：距离、点积与余弦相似度

本讲用**同一组教学向量**，完整计算三种方法，避免只背概念。

把提问编码成 **q=(3,4)**。存放三条候选记忆的向量，暂时设为：**A=(6,8)**、**B=(4,3)**、**C=(-3,-4)**。这些坐标为教学人工设定，并非任何真实Embedding模型输出。

**图3｜q、A、B、C四个教学向量的几何位置。**（PDF中有对应的彩色示意图。）

### 3.1 第一种：欧氏距离（Euclidean Distance）

两点越近，欧氏距离越小。二维公式：

**dist(x,y)=√[(x₁−y₁)² + (x₂−y₂)²]**。

我们来一步一步算：

- q 与 A：√[(3−6)²+(4−8)²]=√(9+16)=**5**。
- q 与 B：√[(3−4)²+(4−3)²]=√(1+1)=**√2≈1.414**。
- q 与 C：√[(3+3)²+(4+4)²]=√(36+64)=**10**。

因此按“距离越小越相近”排序：**B → A → C**。注意：这里A与q方向相同，却比B距离更远，因为A长度较大。

### 3.2 第二种：点积（Dot Product）

点积的规则很简单：对应位置相乘，再相加。

**x·y=x₁y₁+x₂y₂+…+x_dy_d**。

- q·A = 3×6 + 4×8 = **50**。
- q·B = 3×4 + 4×3 = **24**。
- q·C = 3×(−3) + 4×(−4) = **−25**。

如果按“点积越大越相近”排序，则是 **A → B → C**。这和欧氏距离的前两名**相反**。原因不是我们算错了，而是点积同时受到**方向关系和向量长度**影响；长度大的向量有可能获得更大的点积。

### 3.3 第三种：余弦相似度（Cosine Similarity）

余弦相似度的核心是：**先把两个向量长度的影响除掉，重点比较它们的夹角方向。**

**cos(x,y)=(x·y) / (||x||×||y||)**，前提是两个向量的长度都不为0。

已知 ||q||=5；||A||=√(6²+8²)=10；||B||=√(4²+3²)=5；||C||=√(9+16)=5。

- cos(q,A)=50/(5×10)=**1.00**，方向完全一致。
- cos(q,B)=24/(5×5)=**0.96**，方向很接近但并不相同。
- cos(q,C)=−25/(5×5)=**−1.00**，方向完全相反。

按余弦相似度排序得到 **A → B → C**。其中1表示方向完全同向，0表示垂直方向，−1表示完全反向；这些是数学上的几何关系，**不能直接翻译成“语义100%相同 / 语义毫无关系 / 内容互相矛盾”**。例如两个内容相互矛盾的句子仍可能含有高度相关的主题而被映射得很近。

**图4｜距离、点积、余弦三种比较方式的排序。**（PDF中有对应的彩色示意图。）

### 3.4 为什么归一化能改变比较行为？

所谓L2归一化，就是把一个向量每个分量都除以其长度，使新向量的长度变为1。例如 q=(3,4) 归一化得到 **q'=(0.6,0.8)**；A=(6,8)归一化也得到 **A'=(0.6,0.8)**；B=(4,3)归一化得到 **B'=(0.8,0.6)**。

在两边都做单位长度归一化以后，**点积与余弦相似度数值相同**；欧氏距离与余弦相似度也具有单调对应关系：

**||x'−y'||² = 2−2cos(x',y')**。

这意味着：若比较的是同一批单位向量，采用这些分数可以得到一致的相似排序（一个按最大，一个按最小）。工程上是否预先归一化，要遵循具体向量模型和索引的设计，不是所有场景都应盲目处理。

### 3.5 学完这一节，不必再死背三种名词

只需记住三句：欧氏距离看“空间隔得多远”；点积看“方向与长度共同作用的匹配强度”；余弦相似度看“方向有多接近”。随后回到我们的向量例子，你应该能凭 q、A、B、C 的几何关系，**预测为什么不同打分方法对A和B的先后排序会不同**。

## 4. 从“随便指定的数字”到“训练出来的语义坐标”

刚才那些向量由我们人工设定，因此不能证明模型已经理解语言。真正的Embedding模型面对句子“工具超时不能算模型错误”，需要根据**可学习参数**计算出向量。我们用 f_θ(text) 表示这个编码过程，θ表示训练出来的参数。输出通常是一个**固定维度的实数向量**，方便保存到向量索引中。

### 4.1 这是学出来的空间，不是给每个词查人工字典

早期词向量研究，例如Word2Vec（Mikolov等，2013），已经说明可以通过对语言数据中的统计关系进行训练，得到具有某些语义/句法规律的词向量。[1] 之后Sentence-BERT（Reimers与Gurevych，2019）等工作，重点使**完整句子**生成适合用余弦相似度直接比较的表示。[2]

可把训练过程理解为“不断调整坐标系”的过程：遇到希望接近的两个样本，就调整参数使它们的匹配分数提高；遇到不应混淆的样本，则适当降低匹配分数。**但真实训练中存在很多损失函数、负样本采样、批次策略和目标变体，下面只是解释原理的简化比喻。**

**图5｜对比学习中的正样本和困难负样本。**（PDF中有对应的彩色示意图。）

### 4.2 什么叫“正样本”和“负样本”？

假设用户问题是：“为什么要把工具超时从Agent失败里剔除？”对应正确历史记录：“工具超时属于运行环境异常，不能直接算业务决策错误。”这可以作为一组**相关正样本**。另一个完全无关句子如“课程安排在周二”，可以作为负样本。

真正有挑战的是**困难负样本（Hard Negative）**：“已经确认所有工具超时都应当算智能体错误”。这句话和问题字面、主题都很相近，却与原有结论方向相反。如果训练数据从未认真区分否定、逻辑关系和时间，模型就可能把这类句子错误地放到过近的位置。训练质量与数据设计因此十分关键。

SimCSE（Gao等，2021）是典型的对比学习句向量研究，既研究无监督的句子表示学习，也研究使用文本蕴含/矛盾信息的监督方法。[3] 这里引用它，只为说明“如何学习相似关系”的研究思想；不能据此断言所有向量模型都按完全相同方式训练。

### 4.3 什么是对比学习（Contrastive Learning）？

用最通俗的话说：**同一学习任务里，有意识地比较‘应该相近’与‘不应相近’的样本，让模型学习区分它们。** 例如把提问 q、正确记忆 p、干扰记忆 n 分别编码为三个向量，训练时鼓励 sim(q,p) 高于 sim(q,n)。在某些实现中会使用温度参数和Softmax构造损失；现在先理解“训练目标改变表示空间”即可，不要求推导整个损失函数。

这个过程不保证所有未来问题都被正确处理：训练集没有覆盖的新领域、特别长的句子、双重否定、专有名词和跨语言表达，都可能导致差异。Embedding给出的是可计算线索，不是逻辑证明。

## 5. Token Embedding、句向量与注意力中的向量有什么关系？

上一讲曾说“Token变成向量”，本讲又说“整段文本变成向量”，两者是否完全相同？**不是。必须先分清表示层级。**

| 名称 | 一般输入/来源 | 表示对象 | 常见作用 |
|---|---|---|---|
| Token Embedding | 一个Token ID | 单个Token的初始连续表示 | 为模型后续计算提供数值输入 |
| 上下文化隐藏状态 | 多层网络、当前序列 | 特定位置受上下文影响的表示 | 参与注意力、推理和下一词预测 |
| 句子/段落 Embedding | 一段完整文本及其编码模型 | 供整体比较的文本向量 | 语义搜索、聚类、相似匹配 |
| Agent记忆条目 | 文本、元数据、状态等 | 系统中的一条可管理记录 | 长期保存、更新、筛选和调用 |

某些句向量模型会经过Transformer得到一组Token级表示，再通过池化（Pooling）等步骤形成一个整体向量；也有其他结构和训练设计。因此 **“一句话Embedding”不是简单地把每个字的Token ID拼起来，更不是在任何模型里直接取一个随机Token的向量。**

**图6｜Token向量、上下文表示、句向量与可管理记忆的区别。**（PDF中有对应的彩色示意图。）

### 5.1 “模型内部注意力”和“外部语义检索”为什么不能混为一谈？

注意力中的Q/K/V属于模型在处理**已经进入本轮上下文的Token表示**时使用的计算变量。而外部记忆中的Embedding通常是对**尚未放入上下文的候选文本**进行编码，之后在一个独立索引中进行匹配。前者解决输入内部怎样交换信息，后者解决候选信息怎样被提前找到。两条计算链路会衔接，但负责的步骤不同。

### 5.2 维度为什么可能是384、768、1024或更大？

不同向量模型输出维数由其具体架构/配置决定。高维允许模型用更多数值分量表示复杂模式，但“维度更大就一定更好”是错误的。实际效果取决于训练目标、数据、任务类型、语言支持和部署方式。二维图只能帮助我们看懂方向与距离，**不能把真实高维语义空间硬解释成二维坐标图**。

## 6. 向量在“记忆写入”时到底怎样产生？

现在把向量放回Agent的记忆生命周期。假设科研助手收到这样一条消息：

> “第20天确定：新增付费实验尚未授权；先完成不收费的文献核查。此前第10天的运行建议现在作废。”

一个较可靠的记忆模块不能只把整段话交给Embedding模型就结束。它首先要确定哪些是可被记忆的**事件、当前状态、来源和约束**。例如：

- 事件：第20天做出新决定。
- 当前状态：付费实验未授权。
- 当前行动：先进行免费的文献核查。
- 历史关系：第10天建议被新决定取代。
- 来源：来自研究者明确决定（在实际系统中须由可信机制确认）。

之后，系统可以为某一条适合检索的文本表述生成向量，同时把“时间=第20天”“状态=有效”“类别=授权边界”等保存成**结构化元数据**。嵌入向量和原文、元数据通常共同指向同一条记忆记录，而不是向量单独承担所有信息。

**图7｜写入记忆时原文/元数据与向量并存。**（PDF中有对应的彩色示意图。）

### 6.1 为什么不能只存向量，不存原文？

向量像一个用于寻找相关信息的“地址线索”。它通常不能被可靠地无损逆向还原成准确的原始文字，更不能作为一条决定的完整证明。原文中的日期、否定词、具体数量、主体和条件需要被保留下来。真正回答问题时，通常要检索到记录后再读取**原始文本/经验证的结构化字段**，让后续推理有证据可依。

### 6.2 什么是文本分块（Chunking）？

长资料可能包含多个主题，整个文件只用一个向量会把大量信息压缩到同一个表示里，造成细节被稀释。系统可能把长文切成较小的语义段落分别编码，也可能对单条记忆事件采用一条记录一个向量；有时采用“较小块检索、较大上下文返回”的策略。

分块不是越小越好：太小会丢失上下文，例如把“**不得**计入模型失败”分成不同片段就很危险；太大会降低精确匹配的能力、增加返回文本成本。合理方案取决于数据类型、查询、后续模型的理解需求与实际评估。

## 7. 在“记忆读取”时：问题怎样找到候选记忆？

假设系统已保存1万条记忆。用户问：“我们当时为什么取消了继续扩展收费实验的安排？”一个典型的语义检索流程是：

1. **提问编码**：将当前检索问题输入可兼容的查询编码器，得到向量 q。
2. **候选查找**：在历史记忆的向量索引中检索与q相似的若干记录。实际系统可以使用精确或近似搜索，不代表每次必须遍历所有记忆。
3. **读取附属信息**：取回匹配记录的原文、时间、来源、有效期与状态字段，而不仅是一个相似度数字。
4. **过滤与排序**：根据任务和约束进行结构化过滤、时间/状态判断、可选重排；区分历史事实与当前有效决定。
5. **上下文组装**：将真正必要的少量证据放进当前大语言模型的上下文。
6. **生成与核验**：模型基于这些证据进行解释；需要真实权限或环境状态时还要单独核验，不能由相似度代替。

Dense Passage Retrieval（Karpukhin等，2020）是训练提问和段落编码器、再用密集向量进行检索的代表性研究。[4] 这类**双编码器（Dual Encoder）**使候选段落能够预先编码，查询来到时再编码一次问题并匹配候选；从而避免每次都让大模型与每一条记忆一起完成复杂的联合计算。

### 7.1 检索分数是怎样被误解的？

假设以下是纯虚构的向量检索结果：

| 候选记忆 | 余弦得分（虚构） | 历史含义 | 能否直接作为当前行动依据？ |
|---|---:|---|---|
| 第10天：拟新增收费实验 | 0.93 | 旧建议 | 不能；后续可能被否定 |
| 第20天：明确暂不授权 | 0.89 | 当前决定 | 需按可信来源确认；优先级很高 |
| 第22天：整理免费替代方案 | 0.78 | 后续执行计划 | 可能有帮助，但不能单独代替授权 |

若只看相似度，系统可能把**第10天旧建议**当成最优答案，甚至把“建议实验”理解为“实验已获批准”。但得分高只能说明在此向量模型及检索设置下匹配更近，并不能代表事实更加正确、更加新或更加有权限。若有明确的时间与状态字段，就应把它们并入系统判断。

## 8. 相似不等于相同：否定、时间、数字与来源为什么困难？

### 8.1 “已批准”与“未批准”可能在语义空间很近

两句话的主题几乎一样：“本周批准了扩充实验”“本周没有批准扩充实验”。普通主题相似检索可能都认为与“实验批准情况”高度相关。对于寻找材料而言，这未必是检索错误：**两句话本来就在谈同一事项**。真正的问题是后续模型必须读取原文，正确识别“未”字，必要时再核对状态和时间。

### 8.2 语义相似不会自动处理事件先后

把“6月提出A方案”“7月暂停A方案”“8月再次讨论A方案”放在同一向量空间，三条记录可能都靠得很近。**向量中的相似度通常不直接等于有效性的时间顺序。** 如果问题问“现在允许做什么”，必须有时间关系与状态维护；如果问题问“最早提出了什么”，则应优先使用历史事件。

### 8.3 数字、文件名和专有标识可能需要精确匹配

例如一个问题问：“编号F0b-17的实验出现了什么错误？”语义检索可能把相似描述或相近编号的记录召回，却不能保证编号精确。可将“F0b-17”视为结构化键做精确过滤，再对内容使用语义检索；必要时在原始文本中逐字符比对。

### 8.4 模型或版本改变后，旧向量可以继续用吗？

两个Embedding模型就算都输出768维，也**不意味着**坐标对应同一语义空间。直接把旧模型生成的历史向量和新模型生成的查询向量比较，通常没有可靠的语义保证。常见做法是保存模型标识与版本，在模型切换时评估是否需要重新编码（Re-embedding）与重建索引，并验证数据及可复现性。

### 8.5 中文、英文与领域术语怎么办？

跨语言检索需要能处理相应语言、并经过合适训练与评估的多语言模型；不是“只要有向量就天然跨语言”。专业领域的术语如“fault attribution”“超时归因”“评测器漏记”也可能因训练分布不同表现不稳。BGE-M3等研究提出了多语言、多检索功能的嵌入方案，但任务适用性仍需单独评估。[5]

## 9. 只做语义搜索够不够？为什么还需要混合检索？

如果你输入一句“找出上一轮讨论过的‘评测器误判工具超时’”，语义匹配十分有用；但如果输入的是一个完整的SHA256校验值，就应该优先做精确查找。综合系统因此常把**稠密语义检索（Dense Retrieval）**、**词项/稀疏检索（Lexical/Sparse Retrieval）**和**结构化过滤（Metadata Filtering）**组合起来。

可以把它们看成三名互补的检索员：第一名擅长看出“不同措辞、相同主题”，第二名擅长发现“关键字、编号、专名”，第三名负责“时间、主体、权限状态”等明确限制。候选汇总后，还可以由一个更昂贵的重排器（Reranker）阅读“查询+候选内容”进行更细判断。

**图11｜语义、词项及结构化过滤的互补关系。**（PDF中有对应的彩色示意图。）

BEIR基准研究在不同领域与任务上比较了多种信息检索路线，提醒我们没有一种简单检索模式在所有条件下必然占优。[6] MTEB则展示了Embedding模型评价涉及多种不同任务，**不能只凭一项语义相似度分数推断记忆检索整体质量**。[7]

## 10. 相似度不是概率，更不是“事实置信度”

很容易把余弦相似度0.92说成“92%可能正确”。**这是概念错误。** 相似度0.92只是两向量夹角关系形成的分数；除非额外针对某个任务进行了严谨的概率校准与验证，否则它不代表92%的正确率，也不代表这条记忆有92%的真实性。

同样，选择Top-5只是在当前排序规则下获取五个候选。若真实答案根本没写入库里，或者早期写入时已经被错误压缩，Top-5再精确也无法恢复不存在的证据。若条目存在但排序在第100位，Top-5同样会漏掉。

### 10.1 用“条件概率链”理解多环节错误

我们在第01—06讲反复区分了写入、检索和使用。这可以用一个简化的条件概率链来表述：

**P(最终正确) = P(候选被找到) × P(正确选用 | 已找到) × P(正确行动 | 已选用)**。

这是将特定成功事件拆成阶段条件概率的教学表达，前提是阶段事件的定义能构成这样的链；并**不**意味着它们是相互独立的。

如果教学中暂设三个条件概率为0.90、0.80、0.85，则最终约为 **0.90×0.80×0.85=0.612（61.2%）**。这并非任何真实智能体的测量数字，只用于说明：**一个环节看起来有90%的表现，不代表多个环节串起来仍是90%。**

## 11. 完整动态案例：一段科研记忆如何走过30天？

请把下面时间线当成**虚构教学故事**，不是对真实研究数据的陈述。

**第4天：第一次问题。** 研究者发现部分工具超时被错误计入模型失败，并要求在未来实验中区分基础设施异常。智能体首先记录原文与可信来源，然后形成“需要区分归因”的记忆候选。向量模型把一段适合检索的描述编码并存入索引。

**第12天：提出改进计划。** 智能体建议建立单独的错误类型字段。计划本身应存为“建议”或“待执行”，而不能写成“已经完成部署”。一条计划信息可能和第4天事实很相似，但其状态不同。

**第20天：修正先前说法。** 研究者明确表示：当前测试已暂停，且新增收费API调用未授权；先分析既有记录。这条新决定应带时间与权限来源入库，同时修订当前状态视图；旧建议仍可用于回答“历史上曾建议什么”，但不应驱动当前付费行为。

**第30天：提出新问题。** 用户问：“为何当初决定把工具超时与模型失败分开？现在可以继续收费复测吗？”智能体先识别该问题包含两层：历史机制解释和当前授权状态。针对前半部分，语义检索应寻找第4天归因依据；针对后半部分，结构化状态/最新决定应定位第20天约束。随后把两类证据一起交给大语言模型，形成“当初为保证归因有效性；当前仍未授权收费复测”的回答。若有实际执行环节，还必须由控制器验证当前的真实授权，而不是根据Embedding得分直接调用付费工具。

### 11.1 如果回答错了，我们该调查哪一层？

- **写入错误**：第20天决定从未被保存，或“未批准”在摘要中变成“已批准”。
- **编码/索引错误**：保存了最新状态，但向量/索引版本不一致，导致找不到它。
- **检索错误**：第4天记录在库里，但第30天的查询只找回了第12天无关建议。
- **候选选择错误**：旧建议分数高于最新决定，排序/筛选没有处理状态。
- **模型解释错误**：正确证据都已放进上下文，模型仍误读否定或条件。
- **执行控制错误**：模型只“建议”收费复测，但系统直接执行了未授权工具调用。

这些是**不同的因果位置**。科研评价时需要尽可能把它们分开，不能把整个系统的错误都说成“Embedding不够准”。

## 12. 从科研阅读角度看：怎么判断一种Embedding研究是否有价值？

对于智能体记忆系统，比较Embedding方法时不要只问“向量维度多大、余弦分数多高”。还应该明确**研究目标是什么**：是句子意义相近？问答检索？跨语言搜索？记录更新后的重建成本？还是长周期决策中的事实正确性？

有些论文展示的是“相似句子聚得更近”；另一些展示的是“问答语料召回更高”；智能体记忆研究则更关心“真正需要的历史信息能否被及时找出、是否被正确解释、能否支持可靠行动”。这几个指标有关联，但不是同一个指标。

当阅读SBERT、SimCSE、DPR、BGE-M3或MTEB时，可以沿着四个问题理解方法：①被编码的单位是词、句子还是段落？②训练时怎样定义‘相近’？③使用怎样的相似度/匹配算法？④报告的是哪种任务指标，能否迁移到有时间状态的智能体记忆场景？

这一阶段只需理解上述判断结构，不必立即设计实验。后续“记忆存储”“检索”“评估”几讲会持续复用它。

## 13. 常见误区：不要让好理解的比喻变成错误原理

**误区1：Embedding就是给一句话编一个唯一编号。** 错。编号只用于识别对象，语义Embedding旨在让某些有用的关系体现在向量比较上，通常不是可逆的唯一编码。

**误区2：向量中的每个数字都有一个可直译的中文含义。** 错。二维语义轴只是教学帮助，真实高维表示的含义通常是分布式的。

**误区3：余弦相似度越高，事实就越可信。** 错。相关性不等于真实性、正确性、时效性或授权有效性。

**误区4：余弦相似度0.90表示90%确定为相同事实。** 错。除非另外完成经过验证的校准，否则它只是几何分数。

**误区5：两句话矛盾，向量就一定方向相反。** 错。矛盾句经常高度相关，因而也可能靠得很近。

**误区6：Embedding和Token Embedding完全是同一个东西。** 错。它们可能共享表示技术，但表示粒度、训练目标和使用阶段不同。

**误区7：向量维度越大，效果必然越好。** 错。不同任务还受训练数据、领域、模型结构、推理延迟和成本影响。

**误区8：同为768维的模型一定兼容。** 错。维度一致不保证坐标语义一致，跨模型混用可能破坏排序。

**误区9：只存向量就能完整保留一条记忆。** 错。原文、时间、来源和状态通常不可或缺。

**误区10：Top-K检索一定包含正确答案。** 错。答案可能未写入、写错、失效或未进入前K名。

**误区11：语义检索一定全面优于关键词检索。** 错。精确编号、专名及复杂约束常需要词项和结构化查找。

**误区12：检索到了合适记忆，智能体就一定会正确行动。** 错。还存在重排、上下文组装、模型理解与控制器执行等独立环节。

## 15. 思考题详细答案：学习重点在推导过程

**答1。** x=(−3,4)含两个分量，所以是二维向量。长度为√[(-3)²+4²]=√(9+16)=5。负号只表示一个坐标方向，不会使长度为负。

**答2。** dist(q,A)=√[(3−6)²+(4−8)²]=5；dist(q,B)=√[(3−4)²+(4−3)²]=√2≈1.414。因此B更近。A与q同向但长度大两倍，欧氏距离比较的是坐标之间实际隔了多远，不只比较方向。

**答3。** q·A=3×6+4×8=50；q·B=3×4+4×3=24。因此按点积从大到小是A、B，与题2的距离排序不同。A虽距离远，但长度更长且同向，形成了更大点积。

**答4。** ||q||=5，||A||=10，||B||=5。cos(q,A)=50/(5×10)=1；cos(q,B)=24/(5×5)=24/25=0.96。所以A与q方向完全一致，B只是接近。

**答5。** 单位向量||x||=||y||=1，故cos(x,y)=(x·y)/(1×1)=x·y。两种评分数值相同，排序自然相同。若一方没有归一化，就不能直接这样推断。

**答6。** 因为两句话共同讨论“实验授权”，主题非常接近，向量检索对它们都给出较高相关性是可能的；这本身不一定是故障。故障发生在系统未能在读取原文后区分“已”和“未”、未结合可信权限状态，却将候选相关性直接当成授权结论。

**答7。** 需要被授权人身份、明确授权的原文与可信来源、授权范围和时间，以及第20天后有没有撤销或修改。仅有Embedding不足以可靠逆向还原这些事实，更不能替代执行层授权核验。

**答8。** 不能仅凭同为768维就默认可比。两个模型的参数和训练目标不同，坐标空间可能不一致。应记录编码模型及版本，做兼容性评估；如有必要重新编码旧库并验证检索效果。

**答9。** 全篇一个向量可能稀释“否决”的局部信息，使检索不能精确定位证据。分块可以改善定位，但不能把“否决”与“方案A”分开到失去语义关系；最好还保留相邻段落、来源和时间，必要时返回更完整的上下文。

**答10。** 不能。可能是正确召回之后被错误排序、过滤；也可能是模型误读新旧时间关系，或者控制器没有核对执行权限。应按“是否写入→是否召回→是否选对→是否进入上下文→是否正确理解→是否正确执行”逐层定位，并留原始记录与输入输出证据。

**答11。** 0.90×0.80×0.85=0.612，即61.2%。若明确是按阶段事件定义的条件概率，链式法则本身不要求独立；若这些数字并非正确的相应条件概率，就不能随意相乘解释为实际成功率。数值为纯教学假设。

**答12。** 可分七步：①识别问题包含“历史原因”和“当前状态”两部分；②按语义检索有关方案A的历史证据；③按时间与明确状态字段读取最近的暂停/恢复决定；④核对原文、来源及有效性，排除被取代的旧建议；⑤将相关证据及冲突信息交给当前上下文；⑥模型据此解释暂停原因与当前是否允许恢复；⑦如果涉及实际运行或收费动作，控制器还必须独立核验现实授权。这样就将“相关、有效、正确行动”三个层次分开。

## 16. 本讲知识地图：用一条完整计算链重建全部概念

请不要只记“Embedding可以把文字变成向量”。试着闭上眼睛复述下面过程：

**过去的一条研究决定** → 保存原文与时间/来源/状态 → 用指定版本的Embedding模型编码适合检索的文本 → 在向量索引里存向量与记录关联 → **今天的查询** → 采用兼容模型编码查询 → 用余弦相似度、点积或距离查找候选 → 配合关键词/状态过滤与必要的重排 → 读取原文、核对新旧决定 → 将合格证据放入当前大语言模型上下文 → 模型解释并提出下一步 → 控制器负责验证外部行动的实际权限与结果。

这个动态模型能帮助你解释“为什么需要Embedding”，也能提醒你：**Embedding只是智能体记忆系统的一个可替换模块，不是完整的记忆、推理或可靠性保证。**

## 17. 可核查的原始研究文献与延伸阅读

以下文献均为真实的公开研究，写明课程中所用对应概念。数字例子和科研助手时间线均为本讲**教学原创示意**，不来自论文实测。
