Deployment stack checklist
- model architecture/config
- checkpoint/weights
- tokenizer + chat template
- inference runtime
- precision / quantization
- device RAM/VRAM
- context length + KV cache
- batching / concurrency
- application or API layer

Lesson:
- Model size in GB is not the same as runtime memory.
- The same checkpoint can be served by different runtimes.
- Reproducibility requires pinning both model revision and runtime settings.
