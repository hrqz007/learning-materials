
========================================================================
实验1：2x3 × 3x2 —— 每个输出格子都是一次 Dot Product
========================================================================
A =
 [[1. 2. 3.]
 [4. 5. 6.]]
A.shape = (2, 3)
B =
 [[ 7.  8.]
 [ 9. 10.]
 [11. 12.]]
B.shape = (3, 2)

逐格手算：
C[0,0] = 1*7 + 2*9 + 3*11 = 58
C[0,1] = 1*8 + 2*10 + 3*12 = 64
C[1,0] = 4*7 + 5*9 + 6*11 = 139
C[1,1] = 4*8 + 5*10 + 6*12 = 154

手写 manual_matmul(A, B) =
 [[ 58.  64.]
 [139. 154.]]
NumPy A @ B =
 [[ 58.  64.]
 [139. 154.]]
结果完全一致： True
输出 Shape： (2, 2)

========================================================================
实验5：一个 Batch 经过线性权重矩阵
========================================================================
X_batch.shape = (3, 2)   # [batch=3, input_dim=2]
W_linear.shape = (2, 4)  # [input_dim=2, output_dim=4]
Y_linear.shape = (3, 4)  # [batch=3, output_dim=4]
Y_linear =
 [[ 2.1  -1.8   1.3   4.4 ]
 [-0.95  1.1  -0.35 -1.8 ]
 [ 0.3   0.6   0.9   1.2 ]]
第1个样本的输出 = [ 2.1 -1.8  1.3  4.4]
它等价于 [1,2] 分别和 W 的4个列向量做点积。

========================================================================
实验6：微型 Transformer 的 Q / K / V 线性投影
========================================================================
X_tokens.shape = (4, 3) # [sequence=4, hidden=3]
W_Q.shape = (3, 2)       # [hidden=3, q_dim=2]
Q.shape = (4, 2)
Q =
 [[2. 1.]
 [1. 2.]
 [1. 1.]
 [1. 1.]]
K.shape = (4, 2)
K =
 [[ 1.5  -1.  ]
 [ 1.   -0.5 ]
 [ 0.5   0.5 ]
 [ 0.75 -0.25]]
V.shape = (4, 2)
V =
 [[1. 2.]
 [1. 1.]
 [2. 1.]
 [1. 1.]]
结论：同一个 X 乘不同的可学习权重矩阵，会得到不同的表示 Q/K/V。

========================================================================
实验总结
========================================================================
1. (m,n) @ (n,p) -> (m,p)：中间维必须相等，外侧维被保留。
2. 输出矩阵的每个元素，本质上都是：左矩阵的一行 dot 右矩阵的一列。
3. 矩阵乘法不是逐元素乘法。
4. 神经网络用 X @ W 一次处理一批样本和多个输出神经元。
5. Transformer 的 Q=XW_Q、K=XW_K、V=XW_V 只是同一规则的大规模版本。
