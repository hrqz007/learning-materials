实验3：只改变 Bias，观察发生什么
======================================================================
原 b = [ 0.2 -0.3]
新 b2 = [10.2 -5.3]
Y_b2 - Y =
 [[10. -5.]
 [10. -5.]
 [10. -5.]]
结论：同一个输出维度，对所有样本都平移相同的 bias 差值。

======================================================================
实验4：只改变一列 Weight，观察哪个输出受影响
======================================================================
W2 =
 [[ 1.  -1. ]
 [ 4.   0. ]
 [-1.   1.5]]
原 Y =
 [[-2.3   2.2 ]
 [ 1.2   2.7 ]
 [ 3.45  1.45]]
新 Y_W2 =
 [[-4.8   2.2 ]
 [ 2.2   2.7 ]
 [ 6.7   1.45]]
差值 Y_W2 - Y =
 [[-2.5   0.  ]
 [ 1.    0.  ]
 [ 3.25  0.  ]]
结论：只改 W 的第0列，主要直接改变第0个输出；第1个输出保持不变。
