实验2：构造一个真正的 LLM 风格 Tensor：X.shape = (B, T, D)
==============================================================================
X3 shape = (2, 3, 4)   含义 = (B=2, T=3, D=4)
W shape  = (4, 2)   含义 = (D=4, O=2)
Y3 shape = (2, 3, 2)   预期 = (B=2, T=3, O=2)
X3[0, 0] = [0.  0.1 0.2 0.3]
Y3[0, 0] = [0.35 0.15]
手工验证第一个 Token： [0.35 0.15]

==============================================================================

==============================================================================
X_flat shape = (6, 4)
Y_flat shape = (6, 2)
Y_restore shape = (2, 3, 2)
与直接 X3 @ W + b 完全一致： True

==============================================================================
实验4：逐 Token 循环 == 三维直接矩阵乘法
==============================================================================
逐 Token 循环与三维直接计算一致： True
这说明 Linear 并没有混合不同 Token；它只对最后一个 D 维做相同映射。

==============================================================================
实验5：Bias Broadcasting 在 (B,T,O) 上怎样发生
==============================================================================
Z3 shape = (2, 3, 2)
b shape  = (2,)
Y3_again 与 Y3 一致： True
Y3_again - Z3 的第0个样本 =
 [[ 0.1 -0.2]
 [ 0.1 -0.2]
 [ 0.1 -0.2]]
可以看到每个 Token 都加上同一个 b = [ 0.1 -0.2]

==============================================================================
实验6：改变 Batch Size 或 Sequence Length，不会改变 Linear 参数数量
==============================================================================
D = 4 , O = 2
Linear 参数量 = D*O + O = 10
当前 B=2, T=3，参数量仍然是 10
即使 B=128, T=4096，只要 D 和 O 不变，这一层参数量仍然不变。

==============================================================================
实验7：PyTorch nn.Linear 直接接收三维 Tensor（若已安装 PyTorch）
==============================================================================
PyTorch 输入 shape = (2, 3, 4)
PyTorch weight shape = (2, 4)
PyTorch 输出 shape = (2, 3, 2)
PyTorch 与 NumPy 结果一致： True

==============================================================================
实验结束：本讲最重要的结论
==============================================================================
1. Batch 不是给每个样本复制一套参数，而是让很多样本共享同一套参数并行计算。
2. 对 (B,T,D) 做 Linear，本质上是对每个 Token 的最后一维 D 使用同一套 W、b。
3. (B,T,D) -> Linear(D,O) -> (B,T,O)，前面的 B、T 轴被保留。
4. Batch Size 和 Sequence Length 影响计算量/显存，但不直接改变这一层的参数数量。
