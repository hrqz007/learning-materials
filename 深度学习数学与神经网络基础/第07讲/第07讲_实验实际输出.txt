==============================================================================
实验1：手算一个神经元的加权和 z = x·w + b
==============================================================================
x = [ 2. -1.  3.] shape = (3,)
w = [ 0.5 -2.   1. ] shape = (3,)
b = 0.2
逐项贡献 x*w = [1. 2. 3.]
贡献之和 = 6.0
z = x·w + b = 6.2
np.dot(x, w) + b = 6.2

==============================================================================
实验2：只改变一个输入特征，观察 z 怎样变化
==============================================================================
原始 x = [ 2. -1.  3.] 原始 z = 6.2
改变后 x = [ 4. -1.  3.] 改变后 z = 7.2
z 的变化量 = 1.0
理论变化量 = Δx1 * w1 = 1.0
结论：某个输入对 z 的影响大小与对应 weight 直接相关。

==============================================================================
实验3：Weight 的正负号决定输入增加时 z 往哪个方向变化
==============================================================================
特征1 增加 1：weight= 0.50, z变化= 0.50
特征2 增加 1：weight=-2.00, z变化=-2.00
特征3 增加 1：weight= 1.00, z变化= 1.00
说明：正权重会使该输入增加时 z 增大；负权重会使 z 减小；绝对值越大，单位变化影响越大。

==============================================================================
实验4：Bias 像整体平移项，不依赖某一个输入特征
==============================================================================
b=-2.0 -> z= 4.00
b= 0.0 -> z= 6.00
b= 0.2 -> z= 6.20
b= 3.0 -> z= 9.00
结论：改变 bias 会整体移动神经元的 pre-activation z。

==============================================================================
实验5：多个神经元组成一层，本质就是矩阵乘法
==============================================================================
W shape = (3, 2)
b_vec shape = (2,)
整层一次计算 z_layer = [6.2 3.2]
逐神经元计算 = [6.2 3.2]
两种方式完全一致： True

==============================================================================
实验6：Batch 中的多个样本共享同一个神经元/同一层参数
==============================================================================
X shape = (3, 3)
W shape = (3, 2)
Z_batch shape = (3, 2)
Z_batch =
 [[ 6.2  3.2]
 [ 0.2  4.2]
 [-0.3  1.2]]
第一个样本结果与实验5一致： True

==============================================================================
实验7：权重大小不等于现实世界中的“因果重要性”
==============================================================================
x = [1000.    1.]
w = [0.001 0.8  ]
逐项贡献 x*w = [1.  0.8]
虽然 w1=0.001 远小于 w2=0.8，但当前样本中两项贡献分别为 [1.  0.8]
结论：weight 的解释依赖输入尺度、网络上下文与训练过程，不能简单等同于现实因果重要性。

==============================================================================
实验8：可选 PyTorch 对照 - nn.Linear 的 pre-activation
==============================================================================
PyTorch weight shape = (2, 3)
PyTorch bias shape   = (2,)
PyTorch 输出 z       = [6.2 3.2]
与 NumPy 一致： True

==============================================================================
实验结束：本讲必须记住的结论
==============================================================================
1. 一个最基本神经元先计算 z = x·w + b。
2. 每个输入都有对应 weight；x_i*w_i 是该输入对当前 z 的直接数值贡献。
3. 多个神经元并排，就是把多个 w 堆成矩阵 W，一次做 x@W+b。
4. Batch 中所有样本共享同一套 W、b。
5. 目前的 z 仍只是线性/仿射结果；下一步还需要 Activation 才能构成真正有非线性表达能力的深层网络。
