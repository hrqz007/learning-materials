第20讲：Gradient（梯度）

建议学习顺序：
1. 第20讲_讲义_Gradient梯度.pdf
2. 手算讲义中的二维例子：L=(w1-2)^2+2(w2+1)^2
3. 运行 lesson20_gradient_experiment.py
4. 对照 第20讲_实验实际输出.txt
5. 阅读 第20讲_实验设计_Gradient方向范数与步长.pdf
6. 完成 第20讲_练习题与答案.pdf
7. 最后用 第20讲_核心概念速查卡.pdf 复盘

本讲最低闭环：
- 能说出 Gradient 是多个偏导数组成的局部敏感度集合；
- 能解释 Gradient / Negative Gradient 的方向含义；
- 能区分 Gradient 与 Learning Rate / Optimizer；
- 知道参数 Tensor 与其 Gradient 通常具有相同 Shape；
- 知道 Gradient 是局部一阶信息，不保证直接到全局最低点。
