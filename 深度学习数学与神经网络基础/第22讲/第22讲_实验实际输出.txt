第22讲：Chain Rule 实验
========================================================================

[实验1] 两段链：x -> y -> L
x=2.000, y=7.000, L=49.000
dL/dy=14.000, dy/dx=3.000
Chain Rule: dL/dx=42.000
数值差分 dL/dx=42.000000, 误差=8.969e-10

[实验2] 更长的链：x -> a -> b -> L
x=2.000 -> a=4.000 -> b=5.000 -> L=25.000
局部导数: dL/db=10.000, db/da=1.000, da/dx=2.000
总导数: dL/dx=20.000

[实验3] 神经元链：w -> z -> ReLU -> L
x=2.000, w=1.500, b=-1.000, target=4.000
z=2.000, a=ReLU(z)=2.000, L=4.000
dL/da=-4.000, da/dz=1.000, dz/dw=2.000
dL/dw=-8.000, dL/db=-4.000
数值差分 dL/dw=-8.000000, dL/db=-4.000000

[实验4] ReLU gate 关闭时的梯度
z=-2.000, ReLU(z)=0.000, L=16.000
dL/da=-8.000, da/dz=0.000, 所以 dL/dw=-0.000

[实验5] 分支图：同一个 x 通过两条路径影响 L
u=x^2=4.000, v=3x=6.000, L=u+v=10.000
路径1贡献=4.000, 路径2贡献=3.000
dL/dx=路径1+路径2=7.000
数值差分 dL/dx=7.000000
