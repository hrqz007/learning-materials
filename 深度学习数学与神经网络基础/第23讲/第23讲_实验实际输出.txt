[实验1] Add / Multiply / Square / ReLU 的局部 backward 规则
Add node: z=a+b, a=2.0, b=-3.0, 收到梯度=4.0
  传给a的梯度 = 4.000000
  传给b的梯度 = 4.000000
Multiply node: z=a*b, a=2.0, b=-3.0, 收到梯度=4.0
  传给a的梯度 = incoming*b = -12.000000
  传给b的梯度 = incoming*a = 8.000000
Square node: z=a^2, a=2.0, 收到梯度=4.0
  传给a的梯度 = incoming*2a = 16.000000
ReLU node: a=2.0 -> 梯度 4.000000; b=-3.0 -> 梯度 0.000000

[实验2] 完整计算图：手工 Forward + Backward
Forward: x=2.0, w=3.0, b=-1.0, target=4.0
  m=w*x = 6.000000

  a=ReLU(z) = 5.000000
  d=a-target = 1.000000

Backward:
  dL/dL = 1.000000
  dL/dd = 2.000000
  dL/da = 2.000000

  dL/dz = 2.000000
  dL/dm = 2.000000
  dL/db = 2.000000
  dL/dw = 4.000000
  dL/dx = 6.000000
