=== 第24讲：一个神经元的 Backpropagation ===

[实验1] 向量输入单神经元：手工 Forward + Backward
x = [ 2. -1.  3.]
w = [ 0.5 -2.   1. ]
b = 0.200000, target = 5.000000
z = x·w + b = 6.200000
a = ReLU(z) = 6.200000
error = a-target = 1.200000
Loss = error^2 = 1.440000
Backward:
  dL/da = 2.400000
  da/dz = 1.0
  dL/dz = 2.400000
  dL/dw = [ 4.8 -2.4  7.2]
  dL/db = 2.400000
  dL/dx = [ 1.2 -4.8  2.4]
  shapes: x(3,), w(3,), dL/dw(3,), dL/dx(3,)

[实验2] 数值差分 Gradient Check

  x[2]: manual=2.400000, numeric=2.400000, abs_err=8.642e-11

[实验3] 权重梯度与输入值的关系
  dL/dw[0] = dL/dz * x[0] = 2.400000 * 2.000000 = 4.800000
  dL/dw[1] = dL/dz * x[1] = 2.400000 * -1.000000 = -2.400000
  dL/dw[2] = dL/dz * x[2] = 2.400000 * 3.000000 = 7.200000
  直觉：同一个上游梯度 dL/dz，会被各输入 x_i 缩放后分配给对应 w_i。

[实验4] 用梯度做一次最小参数更新
