========================================================================
实验5：Self-Attention 为什么要付出 T^2 代价
========================================================================
T=  128: T^2=       16384 个 score，单 Head 原始 fp16 score 约     0.03 MiB
T=  256: T^2=       65536 个 score，单 Head 原始 fp16 score 约     0.12 MiB
T=  512: T^2=      262144 个 score，单 Head 原始 fp16 score 约     0.50 MiB
T= 1024: T^2=     1048576 个 score，单 Head 原始 fp16 score 约     2.00 MiB
T= 2048: T^2=     4194304 个 score，单 Head 原始 fp16 score 约     8.00 MiB
T= 4096: T^2=    16777216 个 score，单 Head 原始 fp16 score 约    32.00 MiB
T= 8192: T^2=    67108864 个 score，单 Head 原始 fp16 score 约   128.00 MiB

========================================================================
实验6：Transformer 训练可并行，但自回归生成仍然逐 Token
========================================================================
生成第 1 个新 Token 前，需要已有前 0 个新 Token 的结果
生成第 2 个新 Token 前，需要已有前 1 个新 Token 的结果
生成第 3 个新 Token 前，需要已有前 2 个新 Token 的结果
生成第 4 个新 Token 前，需要已有前 3 个新 Token 的结果
生成第 5 个新 Token 前，需要已有前 4 个新 Token 的结果
生成第 6 个新 Token 前，需要已有前 5 个新 Token 的结果
生成第 7 个新 Token 前，需要已有前 6 个新 Token 的结果
生成第 8 个新 Token 前，需要已有前 7 个新 Token 的结果
因此：Transformer 的优势主要体现在训练和层内计算的并行性；自回归解码时间轴仍然是串行的。
